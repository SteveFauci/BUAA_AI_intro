# BUAA AI StudyMap：人工智能导论复习系统

[![BUAA](https://img.shields.io/badge/BUAA-人工智能导论-orange.svg)](#)
[![作业设计](https://img.shields.io/badge/作业设计-AI%2BX创意-blue.svg)](#)

这是一个给北航《人工智能导论》期末复习用的小工具。题目原来来自课程资料里的 PDF，我整理成了 `questions.json`，再做成网页，方便平时背题、练习多选、模拟考试、看错题和简单分析复习情况。

## 运行

```bash
cd ~/Developer/aicourse
python3 -m http.server 4173
```

然后打开：

```text
http://localhost:4173/
```

## 功能

- 顺序刷题，保留上次进度
- 点选选项后立即显示正确答案
- 答错自动加入错题本
- 错题复习模式中答对会自动移出错题本
- 单选/判断和多选分开训练
- 多选题先选择多个选项，再提交答案；漏选、多选、错选均不得分
- 模拟考试：随机抽取 60 题，限时 30 分钟，左侧答题卡显示作答状态，交卷后统一评分
- 考试错题自动进入错题本，并按知识模块统计薄弱点
- 动态知识图谱：以“北航人工智能导论”为中心，向外发散课程模块、知识子类和题目样例，并显示掌握度
- App 化交互：桌面端左侧快捷导航，移动端底部导航；练习页提供题目列表侧栏和底部操作栏
- 学习分析：根据本地答题日志统计总体正确率、模块正确率和复习建议
- 放松一下：内置 2048 小游戏，支持撤销、删除机会、请求支援和重新开始
- 记录新版页面之后的答题日志
- 可清空错题记录
